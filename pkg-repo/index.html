ProBAN package repository

This is the package repository for ProBAN, an OPNsense plugin. Add it once and ProBAN shows up under System → Firmware → Plugins; new versions then arrive through OPNsense's normal update check.

One-time setup

From the firewall's shell (console option 8, or SSH):

mkdir -p /usr/local/etc/pkg/keys
fetch -o /usr/local/etc/pkg/keys/proban.pub https://freeflite.github.io/PROBan/proban.pub
fetch -o /usr/local/etc/pkg/repos/ProBAN.conf https://freeflite.github.io/PROBan/ProBAN.conf

Then go to System → Firmware → Plugins, refresh, and install os-proban.

Every package is signed, and pkg refuses anything that doesn't verify against proban.pub. The same key is in the source repository if you want to compare.
