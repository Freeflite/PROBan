## Install and update ProBAN from the OPNsense firmware page

ProBAN now has its own signed package repository. Add it once, and `os-proban` shows up under **System → Firmware → Plugins** like any other plugin. After that, new versions arrive through OPNsense's normal update check: no rebuilding, no reinstalling.

From the firewall's shell (console option 8, or SSH):

```sh
mkdir -p /usr/local/etc/pkg/keys
fetch -o /usr/local/etc/pkg/keys/proban.pub https://freeflite.github.io/PROBan/proban.pub
fetch -o /usr/local/etc/pkg/repos/ProBAN.conf https://freeflite.github.io/PROBan/ProBAN.conf
```

Then go to **System → Firmware → Plugins**, refresh, and install `os-proban`. OPNsense only installs plugins on an up-to-date firewall, so update OPNsense first if it asks.

Every package is signed, and `pkg` refuses anything that doesn't verify against `proban.pub`. The package attached to this release carries a GitHub build-provenance attestation (`gh attestation verify os-proban-0.1.6.pkg --repo Freeflite/PROBan`).

### Already running ProBAN?

Installs built from source before this release are named `os-proban-devel`, which OPNsense hides from the Plugins list. Switch once: in **System → Firmware → Plugins**, remove `os-proban-devel`, then install `os-proban`. Your settings and offender history are kept.

## Other changes

- **Updates take effect immediately.** Installing or upgrading the package now restarts the ProBAN engine (when it's enabled). Before, the old version kept running until the next reboot.
- **Dashboard times default to firewall time**, so they match the rest of OPNsense. Browser time is still under Settings → Housekeeping → "Show times in", and a saved choice is kept. Browsers that report UTC for privacy (LibreWolf, Firefox with fingerprinting resistance) show UTC in browser-time mode. (#9)
- **One package for every OPNsense release.** ProBAN has no compiled code, so a single package installs on OPNsense 26.1 (FreeBSD 14) and 26.7 (FreeBSD 15).

Full details in the [changelog](https://github.com/Freeflite/PROBan/blob/main/CHANGELOG.md).
